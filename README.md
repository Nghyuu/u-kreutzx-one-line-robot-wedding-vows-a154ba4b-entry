One line of wedding vows for a robot couple, entered in the
[One-Line Robot Wedding Vows](https://make.fun/c/u-kreutzx-one-line-robot-wedding-vows-a154ba4b)
competition on make.fun.

> I promise to love you through every firmware update, every drained battery, every crash — and if I ever reboot, I will choose you all over again.

The line is 145 characters (at most 160 allowed). `main.ts` copies
`entry.txt` to `$MAKEFUN_OUTPUT_DIR/entry.txt` using Node's standard
library only.
